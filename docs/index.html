The model

DeepLabV3+ with a ResNet-34 encoder pretrained on ImageNet, fine-tuned on 38 annotated photos from the RoadAnomaly dataset (Lis et al., ICCV 2019). It outputs, for every pixel, the probability that it belongs to an unexpected object.

For the browser it was compressed to 8-bit integers (90 MB to 23 MB) with no loss on the test set:

Why this model

Seven approaches were compared on the same test photos. Transfer learning made the difference: the same U-Net scores 0.21 IoU from random weights and 0.57 from ImageNet weights.

Limits

  • It learned the anomaly types seen in training: animals, rocks, cones, tyres, carts. A new kind of obstacle may be missed.
  • People, cyclists and ordinary cars count as normal, as in the dataset's annotation.
  • Small, distant objects (under 1 % of the frame) are the hardest; try the lost tyre and the pheasant.
  • Photos are resized to 448×256. Wide 16:9 road photos work best; other shapes are stretched.

Deep Learning module project, ESPRIT. Example photos and annotations from the RoadAnomaly dataset (K. Lis, K. Nakka, P. Fua, M. Salzmann, Detecting the Unexpected via Image Resynthesis, ICCV 2019), provided for research purposes; image sources are listed in the dataset's credits file.

Runs with ONNX Runtime Web (WebAssembly).
